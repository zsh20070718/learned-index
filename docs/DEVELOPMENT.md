# 开发记录

## 2026-09-20：扩展 benchmark 查询负载

- 新增 TLI 格式兼容的静态点查询生成器，补足上游字符串分支忽略未命中比例的限制；没有修改被测索引。
- 支持固定次数的未命中、uniform/热点访问及固定随机种子，缺失键在完整数据集上检查不存在。
- 新增五种点查询组合，批量实验从 32 扩展到 52 组；每份负载记录实际数量、热点源键分布、唯一键数及输入输出哈希。
- 比例使用有界十进制精确计算，包含 29% 整数边界和极端指数拒绝测试，避免配置比例与实际次数偏离。
- 验证：六项生成器测试通过，CTest 3/3、52 组校验及计时通过；最终本地证据为 `results/smoke-wjtg_y51/`，被测索引及上游源码未修改。
- 保留原有八种读写/区间负载；新增内容只扩展 benchmark，不增加索引算法。

## 2026-09-20：增强 benchmark 测量与校验

项目定位：开发字符串索引 benchmark，接入和比较已有实现，不开发索引算法。

- 为查询结果增加编译器屏障，防止无校验计时路径中的实际查询被优化掉；早期吞吐量不与新版直接比较。
- 独立 map 参照检查查询、每次插入后读回，并在操作完成后检查全部预期键值；通过故障注入测试校验器本身。
- 保留 ART/StdMap 两种比较项、两种键形态和八种负载，共 32 组。
- 新增有界规模参数、1–10 轮重复测量、逐轮样本、中位数及离散程度；记录数据和负载哈希以便复现。
- 验证：离线构建通过，CTest 2/2；32 组负载各重复 3 轮，共 96 个吞吐量样本，本地证据在 `results/smoke-md60ji3x/`。
- 后续推进已有学习型索引适配、未命中及偏斜访问负载、真实数据和统一测量口径。
